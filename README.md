# 🧠 Awesome Kanban Board

Интерактивная Kanban-доска на React — с возможностью добавления, перемещения и описания задач. Данные сохраняются в `localStorage`. Поддерживается адаптивная вёрстка.

## 🔍 Функциональность

- ✅ Добавление задач в Backlog
- 🔄 Перемещение задач по стадиям: Backlog → Ready → In Progress → Finished
- 📝 Редактирование описания задачи
- 📦 Сохранение состояния в `localStorage`
- 📱 Полностью адаптивна (мобильная версия!)
- 🧑‍💼 Выпадающее меню пользователя

## 🚀 Технологии

- React
- React Router
- LocalStorage
- CSS-модули + media queries
